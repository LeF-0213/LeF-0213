## 👋 소개

데이터로 문제를 구조화하고, AI로 해결책을 구현합니다.
AI 모델링, 데이터 분석, 풀스택 웹 개발을 기반으로 문제를 정의하고 실제 구현까지 이어지는 과정을 반복해서 훈련해왔습니다.
현실의 문제를 데이터로 해석하고, AI와 코드로 실제 동작하는 것을 만드는 데 집중합니다.
기술이 무엇을 하는지뿐만 아니라, 왜 필요한지와 어떻게 작동하는지, 문제 정의부터 동작하는 제품까지의 End-to-End 개발을 목표로 합니다.
